# SimpleYandexMusicRPC
SimpleYandexMusicRPC - улучшенная версия многих RPC для Яндекс музыки. Почти моментальные переключения и многое другое! 


Инструкция по использованию:

1. [Скачать версию последнего релиза](https://github.com/chereau1/SimpleYandexMusicRPC/releases/download/yandexmusic/SimpleYandexMusicRPC.exe)
2. **Запустите exe**
3. **Ожидайте прогрузки(5-10 секунд)**
4. **Включайте свои любимые песни! Лог можете видеть в консоли**
